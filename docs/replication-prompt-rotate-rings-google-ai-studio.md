# Rotate the Rings 类游戏：Google AI Studio 复刻资料与主提示词

## 1. 目标

制作一款 Android APK，复刻参考产品的核心玩法、操作节奏和关卡体验：玩家通过触摸旋转同心环，使环上的缺口与目标方向对齐，逐步解开所有环并进入下一关。

参考产品：Google Play《Rotate the Rings》

https://play.google.com/store/apps/details?id=game.genix.rotate.ring.circle

公开页面核对信息（2026-11-12）：

- 开发者：PixOn Games
- 类型：Puzzle / Sliding
- 评分：4.2 星；约 74K 条评价
- 下载量：1M+
- 商业化：包含广告和应用内购买
- 主要描述：多种彩色环、不同难度关卡、限时、booster、障碍物
- 页面列出的机制：D ring、S ring、C lock ring、Ring lock、爆炸障碍
- 页面反馈暴露的问题：部分高难关卡触控不响应、广告过于频繁、部分内容需要联网、夹杂收集金币等支线内容

## 2. 复刻边界

复刻“玩法和交互范式”，不复制对方的品牌、名称、图标、截图、文案、音乐、代码、关卡文件或受保护素材。

建议新产品暂名：`Ring Unwind`。所有颜色、字体、图标、音效、关卡布局和 UI 文案使用原创内容。产品应达到“核心玩法体验接近参考产品”，但在视觉和品牌上独立。

## 3. 产品定义

### 目标用户

- 喜欢单手、短局、空间推理和解压益智的手机用户
- 希望在通勤、等待、睡前进行 1–5 分钟游戏的用户
- 适合全年龄，但首版避免儿童付费诱导

### 核心循环

1. 进入关卡。
2. 看到 2–6 个同心环、缺口、目标槽位和障碍。
3. 拖动或点击环，使环按允许方向旋转。
4. 将缺口与目标对齐。
5. 正确对齐后环锁定或消除。
6. 所有目标完成后显示成功动画、星级和下一关。
7. 失败时显示重试、使用 booster、返回关卡地图三个选择。

### 首版必须有的玩法

- 同心环渲染与旋转
- 触摸拖动旋转，点击环也可按固定角度旋转
- 角度吸附与容差判断
- 2–6 环的关卡难度递进
- 环上的缺口、目标槽位、颜色/图案匹配
- D ring：旋转范围受限
- S ring：可改变方向或形态的特殊环
- C lock ring：满足条件后才可旋转或解锁
- Ring lock：环之间存在依赖关系
- 爆炸障碍：错误操作或特定条件触发，消耗一次机会或重置局部状态
- 限时关卡与非限时关卡
- 关卡地图、星级、已完成状态和本地进度
- 3 个可解释 booster：撤销一步、冻结计时、自动对齐一个环
- 暂停、重试、音效/音乐开关
- 完全离线可玩首版关卡

### 首版暂不做

- 登录、社交、公会、排行榜
- 真实广告 SDK 和支付 SDK
- 云存档
- 复杂金币商店
- 需要联网才能开始游戏
- 大量支线收集玩法

## 4. 技术建议

优先使用 Android 原生 Kotlin + Jetpack Compose + Canvas；如果 Google AI Studio 生成项目更适合传统 View，也可以使用 Kotlin + Custom View，但必须保持模块边界清晰。

推荐模块：

- `GameScreen`：关卡画布、HUD、暂停层
- `RingModel`：中心点、半径、宽度、当前角度、目标角度、允许方向、类型、锁定状态
- `LevelModel`：环列表、障碍列表、时间限制、目标条件、星级阈值
- `RingPuzzleEngine`：输入命中、旋转、吸附、碰撞、解锁、胜负判断
- `LevelRepository`：本地 JSON/ Kotlin 数据类加载关卡
- `ProgressRepository`：SharedPreferences 或 DataStore 保存进度
- `AudioController`：音效和音乐开关

### 交互实现要求

- 触摸点命中某个环后，只旋转最内层命中的可操作环。
- 使用触摸点相对中心的极角差计算旋转增量。
- 对角度做规范化到 `[0, 360)`。
- 松手时根据关卡规则吸附到最近允许角度；吸附阈值建议 8–14 度，并可按难度调整。
- 禁止环之间出现视觉穿插；每次旋转后立即刷新画布。
- 旋转动画 120–220ms，使用 ease-out；胜利动画不超过 900ms。
- 所有可操作区域至少 44dp；窄环也要提供扩大后的触控命中区。
- 处理屏幕旋转、不同宽高比、刘海和系统字体缩放。
- 游戏主流程不依赖网络。

### 关卡数据格式示例

```json
{
  "id": 1,
  "timeLimitSec": 0,
  "starThresholds": {"three": 0, "two": 2, "one": 5},
  "rings": [
    {
      "id": "r1",
      "radiusDp": 92,
      "widthDp": 28,
      "angleDeg": 35,
      "targetAngleDeg": 180,
      "gapDeg": 48,
      "color": "#54C7FF",
      "type": "NORMAL",
      "allowedDirections": ["CW", "CCW"]
    }
  ],
  "obstacles": [],
  "boosterAllowed": true
}
```

首版至少生成 30 个可玩的关卡：前 10 个教学，11–20 个引入特殊环，21–30 个加入锁、障碍和限时。每关必须可解，不能依赖随机生成。

## 5. 视觉方向

- 深色或柔和浅色背景，突出彩色环。
- 环使用清晰的高对比描边、渐变和轻微阴影。
- 缺口必须一眼可见，不能只靠颜色区分。
- 目标槽位使用轮廓、箭头或发光边框表达。
- 动效服务于反馈：旋转、吸附、锁定、消除、胜利。
- 不使用参考产品的 Logo、截图、角色、商店素材或原文案。

## 6. 质量与验收门禁

### 功能

- 新用户打开后 10 秒内能开始第一关。
- 第一关无需说明书即可完成。
- 每个环都能被准确选中和旋转。
- 旋转不会因误触相邻环而改变错误对象。
- 正确对齐、错误操作、锁定、解锁、爆炸、胜利、失败均有明确反馈。
- 退出应用再打开后，进度和设置仍保留。
- 飞行模式下可完成已安装的首版关卡。

### 稳定性

- 不出现崩溃、卡死、黑屏或触控失效。
- 连续完成 20 关后仍可正常输入。
- 低端 Android 设备保持流畅，避免每帧创建大量对象。
- 屏幕旋转和返回键行为明确。

### 体验

- 首关完成时间约 30–90 秒。
- 普通关卡单局约 1–5 分钟。
- 失败后 2 次点击内可重试。
- 不在 MVP 中插入强制广告或付费墙。

### 交付

- 可构建的 Android Studio 项目
- debug APK
- release unsigned APK 或 AAB 构建说明
- README：运行、构建、关卡格式、测试方式
- 至少 5 张关键页面截图
- 自动化或手工测试清单与结果
- 不使用任何未声明的网络服务、密钥或第三方付费 SDK
